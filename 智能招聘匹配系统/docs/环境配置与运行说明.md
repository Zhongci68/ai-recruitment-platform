# 环境配置与运行说明

## 1. 运行环境

| 组件 | 推荐版本 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| JDK | 17 | 是 | 项目由 Spring Boot 3.3.5 构建 |
| Maven | 3.9+ | 是 | 用于下载依赖、编译和打包 |
| 浏览器 | 新版 Chrome/Edge/Firefox | 是 | 访问系统页面 |
| H2 | 随项目依赖提供 | 否 | 默认数据库，无需单独安装 |
| MySQL | 8.x | 否 | 仅在启用 `mysql` 配置时使用 |
| Python | 无 | 否 | 本项目不使用外部 Python NLP 服务 |
| GPU | 无 | 否 | 匹配算法在 Java 中运行，不需要 GPU |

## 2. 检查 Java 和 Maven

打开 PowerShell，执行：

```powershell
java -version
mvn -version
```

`java -version` 应显示 17 或更高的主版本。`mvn -version` 应同时显示 Maven
版本和它正在使用的 JDK。

如果命令不存在，请安装 JDK 17 和 Maven，并将 `JAVA_HOME` 指向 JDK 安装目录。
也可以使用 IntelliJ IDEA 自带的 Maven。

## 3. 使用默认 H2 数据库启动

默认配置不需要安装 MySQL。进入项目根目录，也就是包含 `pom.xml` 的
`学号_姓名_智能招聘匹配系统` 目录：

```powershell
cd "D:\Programming\linshi\基于 Spring Boot 与 NLP 的智能招聘匹配系统\学号_姓名_智能招聘匹配系统"
```

启动项目：

```powershell
mvn spring-boot:run
```

也可以使用支持 Maven 的 IDE 打开 `pom.xml`，运行主类
`project.RecruitmentApplication`。

启动成功后，控制台会出现类似内容：

```text
Tomcat started on port 8080
Started RecruitmentApplication
```

浏览器访问：

```text
http://localhost:8080
```

首次启动会自动创建 H2 表结构并初始化演示数据。H2 数据文件位于：

```text
学号_姓名_智能招聘匹配系统/data/recruitment.mv.db
```

## 5. 切换端口

修改 `src/main/resources/application.yml` 中的默认端口，或者临时设置环境变量：

```powershell
$env:SERVER_PORT = "8081"
mvn spring-boot:run
```

此时访问 `http://localhost:8081`。

## 6. 打包成 JAR

在项目根目录执行：

```powershell
mvn clean package
```

构建成功后生成：

```text
target/smart-recruitment-system-1.0.0.jar
```

运行：

```powershell
java -jar target/smart-recruitment-system-1.0.0.jar
```

建议仍从项目根目录运行，因为默认 H2 地址是相对于工作目录的 `./data`。

## 7. 使用 MySQL

如果教师电脑已安装 MySQL，可按以下步骤切换：

1. 在 MySQL 中创建数据库 `smart_recruitment`，SQL 见数据库说明文档。
2. 设置 MySQL 连接环境变量。
3. 启用 `mysql` profile。
4. 启动项目。

PowerShell 示例：

```powershell
$env:SPRING_PROFILES_ACTIVE = "mysql"
$env:MYSQL_HOST = "localhost"
$env:MYSQL_PORT = "3306"
$env:MYSQL_DATABASE = "smart_recruitment"
$env:MYSQL_USERNAME = "root"
$env:MYSQL_PASSWORD = "你的MySQL密码"
mvn spring-boot:run
```

Linux/macOS 示例：

```bash
export SPRING_PROFILES_ACTIVE=mysql
export MYSQL_HOST=localhost
export MYSQL_PORT=3306
export MYSQL_DATABASE=smart_recruitment
export MYSQL_USERNAME=root
export MYSQL_PASSWORD='你的MySQL密码'
mvn spring-boot:run
```

详细说明见 [数据库说明](数据库说明.md)。

## 8. 开发环境配置

建议使用 IntelliJ IDEA：

1. 选择 `File > Open`，打开 `学号_姓名_智能招聘匹配系统` 目录。
2. 将 Project SDK 设置为 JDK 17。
3. 等待 Maven 下载依赖并完成索引。
4. 运行 `project.RecruitmentApplication`。

项目第一次构建需要联网下载 Maven 依赖。依赖下载完成后，可离线启动和运行。

## 9. 常见问题

### 端口 8080 已被占用

设置 `SERVER_PORT` 为其他端口，例如 8081，然后重新启动。

### `java` 或 `mvn` 不是内部或外部命令

检查 JDK 和 Maven 是否已安装，并确认 `JAVA_HOME`、`MAVEN_HOME` 和 `PATH`
配置正确。修改环境变量后需要重新打开终端。

### Maven 依赖下载失败

确认网络可用。如果在国内网络环境下速度较慢，可以在 Maven `settings.xml`
中配置可用的镜像。

### H2 数据库文件被占用

同一个 H2 文件数据库不能同时被多个应用进程写入。关闭之前启动的实例，
再重新运行项目。

### 修改数据库文件后数据异常

停止应用，备份或删除 `data/recruitment.mv.db`，再启动应用。删除后系统会
重新创建表并写入演示数据。

### 页面可以打开但接口返回 401 或 403

需要先登录。401 表示未登录或登录已过期；403 表示当前账号角色没有对应权限。

### 中文显示乱码

确认 Java 文件、HTML 文件和配置文件使用 UTF-8 编码。MySQL 数据库应使用
`utf8mb4` 字符集。
