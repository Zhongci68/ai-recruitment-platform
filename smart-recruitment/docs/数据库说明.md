# 数据库说明

## 1. 数据库方案

项目提供两套数据库配置：

| 配置 | profile | 使用场景 |
| --- | --- | --- |
| H2 文件数据库 | `dev` | 默认方案，适合直接演示和课程验收 |
| MySQL | `mysql` | 适合需要使用独立数据库服务时 |

默认启用 `dev`，无需安装数据库。所有配置位于
`src/main/resources/application.yml`。

## 2. 默认 H2 配置

```yaml
spring:
  profiles:
    active: ${SPRING_PROFILES_ACTIVE:dev}
  datasource:
    url: "jdbc:h2:file:./data/recruitment;MODE=MySQL;DATABASE_TO_LOWER=TRUE"
    driver-class-name: org.h2.Driver
    username: sa
    password:
```

关键配置：

- 数据文件：`data/recruitment.mv.db`
- 用户名：`sa`
- 密码：空
- `MODE=MySQL`：使 H2 使用接近 MySQL 的语法模式
- `DATABASE_TO_LOWER=TRUE`：统一处理表名大小写

`./data` 是相对于启动工作目录的路径。应从包含 `pom.xml` 的项目根目录运行，
或者通过 `H2_URL` 指定绝对路径。

可通过以下环境变量覆盖默认值：

| 环境变量 | 默认值 |
| --- | --- |
| `H2_URL` | `jdbc:h2:file:./data/recruitment;MODE=MySQL;DATABASE_TO_LOWER=TRUE` |
| `H2_USERNAME` | `sa` |
| `H2_PASSWORD` | 空 |

### 重置 H2 数据

先停止应用，再删除当前数据文件：

```text
data/recruitment.mv.db
```

重新启动后，JPA 会创建表结构，`DataInitializer` 和 `DemoDataEnhancer`
会写入演示用户、岗位、简历、投递、评价和评论。

删除数据库文件会丢失本地新增数据。需要保留时，请先备份整个 `data` 目录。

### 备份 H2 数据

1. 停止应用。
2. 复制 `data/recruitment.mv.db` 到安全位置。
3. 恢复时，将备份文件放回 `data` 目录并保持原文件名。

## 3. MySQL 配置

### 3.1 创建数据库

在 MySQL 客户端执行以下 SQL：

```sql
CREATE DATABASE IF NOT EXISTS smart_recruitment
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_unicode_ci;
```

本项目不要求手工建表。`spring.jpa.hibernate.ddl-auto` 设置为 `update`，
首次启动时会根据实体类自动创建或更新表结构。

### 3.2 连接参数

| 参数 | 默认值 | 环境变量 |
| --- | --- | --- |
| 主机 | `localhost` | `MYSQL_HOST` |
| 端口 | `3306` | `MYSQL_PORT` |
| 数据库 | `smart_recruitment` | `MYSQL_DATABASE` |
| 用户名 | `root` | `MYSQL_USERNAME` |
| 密码 | 空 | `MYSQL_PASSWORD` |
| 时区 | `Asia/Shanghai` | 在 JDBC URL 中配置 |
| 字符集 | `utf8`/`utf8mb4` | 在 JDBC URL 中配置 |

### 3.3 启动 MySQL profile

PowerShell 示例：

```powershell
$env:SPRING_PROFILES_ACTIVE = "mysql"
$env:MYSQL_HOST = "localhost"
$env:MYSQL_PORT = "3306"
$env:MYSQL_DATABASE = "smart_recruitment"
$env:MYSQL_USERNAME = "root"
$env:MYSQL_PASSWORD = "你的MySQL密码"
mvn spring-boot:run
```

Linux/macOS 示例：

```bash
export SPRING_PROFILES_ACTIVE=mysql
export MYSQL_HOST=localhost
export MYSQL_PORT=3306
export MYSQL_DATABASE=smart_recruitment
export MYSQL_USERNAME=root
export MYSQL_PASSWORD='你的MySQL密码'
mvn spring-boot:run
```

也可以在 IDE 的运行配置中添加同名环境变量。

## 4. 数据表与实体对应关系

| 实体类 | 表名 | 主要用途 |
| --- | --- | --- |
| `User` | `users` | 用户账号、角色、个人资料和状态 |
| `Resume` | `resume` | 简历原文、结构化信息、技能和经历 |
| `Job` | `job` | 岗位信息、要求、关键词、浏览量和评分 |
| `JobCategory` | `job_category` | 岗位分类 |
| `HotJob` | `hot_job` | 热门岗位关联 |
| `Favorite` | `favorite` | 用户收藏岗位 |
| `ApplicationRecord` | `application_record` | 简历投递、匹配分和投递状态 |
| `Interview` | `interview` | 面试时间、方式、地点和状态 |
| `Rating` | `rating` | 用户对岗位的评分 |
| `Comment` | `comment` | 用户对岗位的评论 |
| `AdminAction` | `admin_action` | 管理员操作记录 |
| `UserGroup` | `user_group` | 用户组名称和说明 |

主要关系：

- 一个用户可以有一份简历。
- 一个招聘者可以发布多个岗位。
- 一个岗位属于一个岗位分类。
- 用户与岗位之间可以形成收藏、投递、评分和评论记录。
- 一个投递记录可以关联面试安排。
- 热门岗位与岗位是一对一关联。

主要唯一约束：

- `users.account`
- `job_category.name`
- `user_group.name`
- `favorite(job_id, user_id)`
- `rating(job_id, user_id)`

## 5. 初始化数据

演示数据由以下类在应用启动时创建：

- `project.config.DataInitializer`
- `project.config.DemoDataEnhancer`

初始化内容包括管理员、求职者、招聘者、岗位分类、岗位、简历、收藏、
投递、评分和评论。初始化代码会先检查账号、岗位或记录是否存在，避免重复
创建同样的基础数据。

默认演示账号密码均为 `123456`，仅用于课程作业演示。

## 6. 数据库配置的安全说明

数据库密码不再固定写在配置中，而是通过 `MYSQL_PASSWORD` 环境变量传入。
JWT 密钥也可通过 `APP_JWT_SECRET` 覆盖。

提交到公开 GitHub 前不要提交真实数据库密码、生产环境 JWT 密钥或其他凭据。

## 7. 常见问题

### 启动时报数据库不存在

MySQL 模式要求 `smart_recruitment` 数据库已存在。请先按本文档第 3.1 节
创建数据库。

### 连接 MySQL 被拒绝

检查 MySQL 服务是否启动，端口是否为 3306，以及
`MYSQL_USERNAME`、`MYSQL_PASSWORD` 是否与本地账号一致。

### H2 数据文件在哪里

使用默认配置并从项目根目录启动时，文件位于：

```text
data/recruitment.mv.db
```

如果把工作目录切换到其他地方，H2 会在新的工作目录下查找或创建 `data`
目录，而不是使用项目内的数据文件。

### 更换数据库后的数据是否相同

不会。H2 和 MySQL 是两个独立的存储位置。切换后应用会在目标数据库中重新
建表并运行初始化逻辑，不会自动复制 H2 中的用户新增数据。
